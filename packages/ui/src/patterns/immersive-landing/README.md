# Immersive landing

Beta. This catalog entry embeds the generated standalone landing. It deliberately
does not inject document-level controllers or CSS into an application root.
The ten reusable source sections, states, accessibility and integration contract
are documented in [@axion/landing](../../../../landing/README.md) and the
Marketing stories. Keep the legacy landing example for compatibility.

Generated distribution: `packages/landing/dist`. Update sources and run
`npm run build`; never edit the example or distribution by hand.
