# Navegação entre capítulos

Triângulo discreto, hover estável e acrílico sem sobrepor texto.

Padrão de documento isolado; o código canônico está em packages/landing/src. Use o bundle completo em iframe, mantendo os controles, PT/EN, teclado e movimento reduzido. O Storybook Marketing/Immersive landing documenta a composição executável. Não injete estilos/controllers globais em uma aplicação.

A visualização é conceitual e não estabelece disponibilidade de uma interface do produto. Política de privacidade: item indisponível até existir uma URL confirmada.
