# Terminal

Logs sao texto de exemplo. Em streaming, permita pausar atualizacoes e preservar a posicao de leitura.

## Contrato

`.terminal`, `.terminal-head`, pre.

## Acessibilidade

Evite aria-live no fluxo completo de logs. Anuncie apenas mudancas importantes em uma regiao separada.

## Arquivos

- Exemplo executavel: `examples/terminal.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
