# Campos

Labels permanecem visiveis. Required e type=email usam validacao nativa. Erro, readonly e disabled sao estados independentes; o exemplo de erro e demonstrativo.

## Contrato

`.field`, `.field-check`, `.field-error`; `required`, `disabled`, `readonly`, `aria-invalid`, `aria-describedby`.

## Acessibilidade

Associe for/id, vincule o erro por aria-describedby e nao use placeholder como unico nome.
