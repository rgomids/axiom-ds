# Marca

O nome do produto/repositorio permanece Axion; a assinatura aprovada usa AXIOM, como a referencia. Preserve aspect ratio e o detalhe dourado.

## Contrato

Arquivos em packages/brand/svg. light = tinta escura; dark = tinta clara; mono = tinta unica.

## Acessibilidade

Use alt descritivo quando a marca identifica o produto, e alt vazio se o mesmo nome estiver imediatamente ao lado.

## Arquivos

- Exemplo executavel: `examples/brand.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
