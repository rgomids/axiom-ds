# Tabelas

Preserve cabecalhos em telas pequenas usando rolagem. Ordenacao, paginacao e selecao ainda nao fazem parte deste componente.

## Contrato

table, caption, thead, tbody; `.table-scroll`, `.status`.

## Acessibilidade

Caption descreve os dados. th usa scope=col. Regiao rolavel nomeada e acessivel por teclado.

## Arquivos

- Exemplo executavel: `examples/table.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
