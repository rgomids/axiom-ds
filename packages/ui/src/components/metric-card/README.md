# Metricas

Mostre periodo e unidade no contexto real. A sparkline deste prototipo e decorativa, nao uma visualizacao de dados reais.

## Contrato

`.metric-card`, `.icon-soft`, `.trend`, `.spark`.

## Acessibilidade

Valores legiveis em texto. Grafico decorativo usa aria-hidden; grafico informativo precisa de resumo ou tabela equivalente.

## Arquivos

- Exemplo executavel: `examples/metric-card.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
