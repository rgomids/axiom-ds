# Navegacao

Sidebar e topbar sao composicoes de links, busca e acoes. Os links do exemplo navegam entre secoes reais.

## Contrato

`.side-nav`, `.nav-demo`, `.topbar`, `.environment`, `.user-menu`; `.active` e `aria-current` sincronizados.

## Acessibilidade

Cada nav recebe um nome. Use links para navegar. Se houver menu expansivel, implemente controle de foco e aria-expanded antes de promover o padrao.

## Arquivos

- Exemplo executavel: `examples/navigation.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
