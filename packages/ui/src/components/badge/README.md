# Status e badges

Badges apresentam estado, nao sao botoes. A cor sempre acompanha um texto.

## Contrato

`.pill.green`, `.blue`, `.amber`, `.red`, `.neutral`; `.dot` e decorativo.

## Acessibilidade

Nao dependa de cor. Em atualizacoes assincronas importantes, anuncie uma mensagem curta com role=status no contexto.

## Arquivos

- Exemplo executavel: `examples/badge.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
