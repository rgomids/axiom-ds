# Botoes

Use button para comandos e a com href para navegacao. Apenas uma acao primaria por grupo. O exemplo e um mostruario de estados, sem operacoes de negocio.

## Contrato

`.btn.primary`, `.secondary`, `.ghost`, `.danger`, `.icon-btn`; atributos nativos `disabled`, `type`, `aria-busy`, `aria-label`.

## Acessibilidade

Foco visivel; Enter e Espaco nativos. Botoes so com icone precisam de aria-label e title. Estado carregando preserva o texto e bloqueia a acao com disabled.

## Arquivos

- Exemplo executavel: `examples/button.html`
- HTML de referencia: `markup.html`
- Estado: beta. Validar no contexto do produto antes de adotar.
