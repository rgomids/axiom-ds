# @axion/brand

Nove SVGs aprovados do design system.
A assinatura usa AXIOM, conforme referencia; o produto se chama Axion.

- logo: composicao vertical.
- horizontal: assinatura em linha.
- symbol: simbolo isolado.
- light: tinta escura para fundo claro.
- dark: tinta clara para fundo escuro.
- mono: tinta unica escura.

Preserve as proporcoes e nao recorte o detalhe dourado.
As assinaturas usam curvas vetoriais; o slogan usa Arial/sans-serif.
manifest.json lista todos os ativos.
