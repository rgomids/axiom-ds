# @axion/tokens

Tokens primitivos, semanticos e de componentes.
src/_.tokens.json segue o subconjunto DTCG 2025.10 usado pelo projeto.
dist/tokens.json e um mapa plano de valores resolvidos para consumo,
nao um arquivo DTCG de intercambio.
dist/tokens.css contem variaveis --axion-_ e aliases legados no escopo .axion.

Edite as fontes no repositorio e execute npm run build na raiz.
