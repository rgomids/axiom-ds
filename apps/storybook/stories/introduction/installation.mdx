# Instalação

Os pacotes são privados (versão `0.x`, API ainda não estável) e consumidos do
repositório via npm workspaces ou `npm pack`.

```sh
npm pack --workspace @axion/ui
npm install ./axion-ui-<versão>.tgz
```

React 19 é peer dependency. Importe as fontes (Geist Sans/Mono, locais) e o tema
compilado uma única vez:

```tsx
import '@axion/ui/fonts.css';
import '@axion/ui/theme.css';
import { Button } from '@axion/ui';

export function Save() {
  return <Button>Salvar projeto</Button>;
}
```

Renderize `<Toaster />` uma vez se usar `toast()`. Padrões técnicos
(`DashboardShell`, `LogViewer`, `EvidencePanel`...) são exportados pelo mesmo pacote.

## Tema

Defina `data-theme="light"` ou `data-theme="dark"` no elemento `html`. Portais
(Dialog, Popover, Menu, Toast) herdam o tema do documento. Ilhas de tema
aninhadas não são suportadas.

