# Axiom Design System

Tokens, componentes React acessíveis e padrões técnicos para interfaces de
engenharia do Axiom. Este Storybook é a documentação executável: cada página
pode ser testada com teclado, nos temas Light e Dark e em larguras estreitas.

## Navegação

| Seção            | Conteúdo                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| **Introduction** | Instalação, princípios e regras de acessibilidade                        |
| **Foundations**  | Cores, tipografia, espaçamento, raios, sombras, movimento e ícones       |
| **Components**   | Actions, Forms, Data Display, Navigation, Overlays e Feedback            |
| **Patterns**     | Composições técnicas reutilizáveis (dashboard, execução, workflow, logs) |
| **Examples**     | Telas completas com dados locais simulados                               |

Use a barra lateral (atalho `/`) para buscar, o seletor **Theme** na barra de
ferramentas para alternar Light/Dark e o seletor de viewport para larguras móveis.
Os exemplos usam dados fictícios e não representam funcionalidades disponíveis
no produto.

## Fonte da verdade

```text
Primitives → Semantic tokens → Component tokens → CSS variables → Tailwind/React
```

Git é a fonte técnica; o Storybook demonstra código real, não imagens.
O produto ([rgomids/axiom](https://github.com/rgomids/axiom)) consome os pacotes e
mantém a aplicação e a landing page.
