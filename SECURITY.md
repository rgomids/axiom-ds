# Security policy

Only the latest 0.x release is maintained. Never put credentials or production
data in stories, screenshots or fixtures.

Report suspected vulnerabilities privately using
https://github.com/rgomids/axiom-ds/security/advisories/new when private reporting
is available. Otherwise contact repository owner rgomids through their GitHub
profile to arrange a private channel; do not disclose exploit details publicly.

Maintainers triage reports, assess affected versions and publish fixes and
advisories as appropriate. No response-time guarantee is implied.
Review dependency updates, install scripts and lockfile changes. CI uses read-only
permissions except the isolated Pages deployment job. Fork PRs never deploy.
